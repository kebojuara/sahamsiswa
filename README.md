# Sahamsiswa — Stock Market News Portal

---

## About
This repository contains **Sahamsiswa**, a final project for the **Web Programming** course at **Institut Teknologi Sepuluh Nopember, Surabaya**.  
It is a stock market news website built with **PHP, MySQL, HTML, CSS & JavaScript**. Visitors can read articles about Indonesian stocks, US stocks, and cryptocurrency, search for news, and browse market categories. The project also includes an administration area for managing content.

---

## How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/kebojuara/sahamsiswa.git
   cd sahamsiswa
   ```
2. Create a MySQL database and import `database.sql`.
3. Update the database settings in `config.php` to match your local MySQL setup.
4. Start a local PHP server:
   ```bash
   php -S localhost:8000
   ```
5. Open `http://localhost:8000` in your browser.

Market data requests require an internet connection and depend on the external data services being accessible.
